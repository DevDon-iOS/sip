# Sip

Sip은 Apple Watch와 iPhone을 활용해 **낮잠을 기록하고 돌아볼 수 있도록 돕는 낮잠 측정 앱**입니다.

## 왜 Sip을 만드는가

Apple Watch는 수면 측정 기능을 제공하지만, 밤에는 충전이나 착용 불편 때문에 Watch를 차고 자지 않는 사람이 많습니다. 또한 Apple 건강 앱의 기본 수면 추적만으로는 짧고 불규칙한 낮잠을 의도적으로 시작하고, 낮잠 기록만 따로 모아 확인하고 분석하기 어렵습니다.

Sip은 이 공백에 집중합니다. 사용자가 낮잠을 시작할 때 Apple Watch에서 간단히 측정을 시작하고, 잠에서 깬 뒤 iPhone에서 낮잠 시간과 패턴을 확인할 수 있는 경험을 목표로 합니다.

## 제품 목표

- Apple Watch에서 낮잠 측정을 빠르게 시작하고 종료할 수 있게 합니다.
- 측정한 낮잠을 Apple 건강 데이터와 일관되게 기록합니다.
- iPhone에서 낮잠 기록, 평균 시간, 추세를 쉽게 확인할 수 있게 합니다.
- 민감한 건강 데이터를 최소 권한으로 안전하게 다룹니다.
- 야간 수면 앱을 대체하기보다 낮잠 기록에 특화된 경험을 제공합니다.

## 계획 중인 핵심 경험

1. Apple Watch에서 낮잠 측정을 시작합니다.
2. Watch가 낮잠의 시작 시각과 종료 시각을 기록합니다.
3. 기록이 iPhone과 안전하게 동기화되고 Apple 건강에 저장됩니다.
4. iPhone에서 낮잠 기록과 기간별 통계를 확인합니다.

> 현재 저장소는 초기 개발 단계입니다. 위 흐름 중 일부는 아직 구현되지 않았으며, 구현 상태와 제품 목표를 구분해 관리합니다.

## 현재 개발 상태

| 영역 | 상태 |
| --- | --- |
| iOS 앱 기본 화면 구조 | 초기 구현 |
| HealthKit 권한 요청 및 수면 샘플 저장·조회 | 프로토타입 구현 |
| 낮잠 기록 및 분석 화면 | UI 골격 구현 |
| Apple Watch 측정 화면 | 초기 프로젝트 골격 |
| Watch–iPhone 기록 동기화 | 계획 |
| 낮잠 자동 감지 | 검토 중 |
| 수면 질 점수 | 기준 정의 필요 |

## 개발 원칙

- 실제로 검증된 측정값과 추정값을 구분합니다.
- 사용자가 시작한 낮잠 세션을 기준으로 기록의 출처를 명확히 합니다.
- HealthKit 권한 거부, Watch 연결 끊김, 전송 지연 상황에서도 기록이 유실되지 않도록 설계합니다.
- 자동 감지나 수면 질 평가는 신뢰할 수 있는 기준이 검증되기 전까지 확정 기능으로 제공하지 않습니다.
