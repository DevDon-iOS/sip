# Sip

Sip은 Apple Watch와 iPhone을 활용해 **낮잠이 사용자의 하루 컨디션에 어떤 영향을 주는지 알려주는 개인화 낮잠 코치**입니다.

## 왜 Sip을 만드는가

Apple Watch는 수면 측정 기능을 제공하지만, 밤에는 충전이나 착용 불편 때문에 Watch를 차고 자지 않는 사람이 많습니다. 또한 Apple 건강 앱의 기본 수면 추적만으로는 짧고 불규칙한 낮잠을 의도적으로 시작하고, 낮잠 기록만 따로 모아 확인하고 분석하기 어렵습니다.

Sip은 단순히 낮잠 시간을 저장하는 데서 끝나지 않습니다. 낮잠 전·직후·하루 종료 시점의 간단한 자가 평가와 HealthKit의 사용 가능한 보조 지표를 결합해, 사용자가 어떤 시간대와 길이의 낮잠에서 실제로 더 나은 컨디션을 보였는지 설명합니다.

피드백은 의료적 진단이나 단정적인 인과관계가 아니라 사용자의 반복 기록에서 확인된 변화와 경향을 근거로 제공합니다.

## 제품 목표

- Apple Watch에서 낮잠 측정을 빠르게 시작하고 종료할 수 있게 합니다.
- 낮잠 전·직후·하루 종료 시점의 컨디션을 짧게 기록할 수 있게 합니다.
- 측정한 낮잠을 Apple 건강 데이터와 일관되게 기록합니다.
- 낮잠 시간·시각과 에너지·집중·기분 변화의 관계를 개인별로 분석합니다.
- 오늘의 즉시 피드백과 누적된 개인 패턴을 이해하기 쉽게 제공합니다.
- 민감한 건강 데이터를 최소 권한으로 안전하게 다룹니다.
- 야간 수면 앱을 대체하기보다 낮잠 기록에 특화된 경험을 제공합니다.

## 계획 중인 핵심 경험

1. 사용자가 에너지·집중·기분을 한 번의 짧은 체크인으로 기록합니다.
2. Apple Watch에서 낮잠 권장 시간 확인 후 측정을 시작합니다.
3. Watch가 낮잠의 시작 시각과 종료 시각을 기록합니다.
4. 기상 직후 회복감을 체크하고, 하루가 끝날 때 전체 컨디션을 확인합니다.
5. 기록이 iPhone과 안전하게 동기화되고 Apple 건강에 저장됩니다.
6. Sip이 자가 평가와 선택적으로 허용된 HealthKit 지표를 결합해 오늘의 피드백을 제공합니다.
7. 기록이 쌓이면 효과가 좋았던 낮잠 길이·시간대와 주의할 패턴을 보여줍니다.

> 현재 저장소는 초기 개발 단계입니다. 위 흐름 중 일부는 아직 구현되지 않았으며, 구현 상태와 제품 목표를 구분해 관리합니다.

## 개발 원칙

- 실제로 검증된 측정값과 추정값을 구분합니다.
- 관찰된 연관성과 인과관계를 구분하고, 의료적 진단처럼 표현하지 않습니다.
- 사용자가 시작한 낮잠 세션을 기준으로 기록의 출처를 명확히 합니다.
- HealthKit 권한 거부, Watch 연결 끊김, 전송 지연 상황에서도 기록이 유실되지 않도록 설계합니다.
- 자가 평가만으로도 핵심 피드백이 동작하며 HealthKit은 선택적 보조 신호로 사용합니다.
- 데이터가 충분하지 않을 때는 성급한 개인화 결론 대신 기록 축적 상태를 안내합니다.
